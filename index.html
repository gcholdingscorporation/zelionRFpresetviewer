Rotorflight Preset Viewer

Drop a dump all, diff all or preset file below and it is laid out the way the Rotorflight Configurator lays out its tabs — Governor, Mixer, Servos, Filters, PID Profiles, Rates, Modes and the rest. Drop two files and they are shown side by side with everything they disagree on marked. Everything happens in your browser; nothing is uploaded.

Drag a file — or two, to compare them — anywhere on this page

What it reads
  • set values, master and per profile
  • profile / rateprofile blocks
  • servo, mixer input, mixer rule
  • aux modes and adjfunc adjustments
  • serial, feature, beeper
  • led, color, timer, dma, resource
What it shows
  • Each value next to its firmware default
  • Anything the file changed, highlighted
  • Enum names, ranges and types on hover
  • A searchable list of every value
  • Two files side by side, with the differences marked
  • The original file, with line numbers
Good to know
  • Read-only — it cannot flash or configure anything
  • Values are shown exactly as the CLI printed them
